# Application de gestion des tâches (PHP)

Application web développée en PHP & MySQL (PDO) permettant à des utilisateurs
de gérer leurs tâches avec un système d’authentification et de rôles
(Administrateur et Utilisateur).

## Fonctionnalités
- Connexion / Déconnexion
- Gestion des rôles (Admin / Utilisateur)
- CRUD des tâches
- Sécurité avec PDO

## Technologies utilisées
- PHP
- MySQL
- PDO
- HTML / CSS

## Installation
1. Importer la base de données depuis le dossier `sql`
2. Configurer la connexion dans `db.php`
3. Lancer le projet avec XAMPP
